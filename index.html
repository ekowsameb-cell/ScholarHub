Data Sync

Live Sync via Firebase (recommended)

Turns ScholarHub into a real shared database: every device (admin, cashier, teacher, principal) sees the same live data instantly. Paste your Firebase config once; it's stored on this device and used to connect. Requires internet to sync (works offline otherwise, queues changes).

Manual Data Sync (offline, no cloud)

If you don't connect Firebase, use this: the Admin exports the master file, then other devices Import it. Re-import after any major change.

Tip: keep one device as the source of truth (e.g. the Admin phone). Others import from it.
